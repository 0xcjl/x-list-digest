# Hermes operational contract

Configure model/provider, schedule and timezone from the user's request. This package enables no task. For an authorized daily task, keep its limits, toolsets, working directory and native connection explicit; do not replace global defaults. External manual triggers require an idle target. A dispatched worker owns its running claim, excludes other instances and never recursively cron-runs itself.

Before collecting, require awake/online host, live Hermes Gateway scheduler/ticker, provider access, native Python/browser tools, readable skill and writable runtime lock/cron/data storage. Check native cron status/list and effective next_run_at. Sleeping or stopped hosts cannot guarantee timely dispatch; do not alter power settings or upgrade Hermes automatically.

For the macOS default-profile adapter, doctor returns the native Python/browser_preflight argv. The adapter supports ~/.hermes/hermes-agent, the already authorized ~/.hermes/chrome-debug and CDP http://127.0.0.1:9234. Require CDP response and a process whose arguments match that exact profile/port and whose IPv4 listener covers 127.0.0.1. Hermes' existing psutil supplies process/connection queries. Missing permissions stop without sudo. A launch return value alone is not readiness.

If no browser is active, the preflight may use Hermes' native launch_chrome_debug only for that pre-existing authorized profile. Missing profile, lock, active-but-unreachable browser, wrong port owner or launch failure records browser_backend_blocked. Never close ordinary Chrome, delete locks, copy authentication or silently switch ports/cloud. Other platforms/custom Hermes homes/endpoints require explicit adapter validation. A sandbox query failure is not proof that the user's native runtime also fails.

After preflight, native browser tools must independently prove X login and list accessibility. Verify selected Feishu user identity and root folder before collecting. Browser and archive identity are independent gates. Keep failures explicit and preserve source evidence.

Freeze a new run's rolling window once, exclude completed historical IDs, and use the fixed collector. Init-only recovery uses the same directory without resume=True. Budget-stopped unfinished recovery requires authorize_resume plus remaining cumulative budget and the same session. Preserve original windows/observations. Archive failures recover analysis/publication only, not new collection.

Finish, merge all same-day completed runs, and archive even honest low-information/partial days. Determine Sunday from archive date and configured timezone, not the day recovery executes. Weekly statistics and sample limitations must be present in local body and remote readback, including previously verified Sunday reports. Save revision-protected write checkpoints and source ownership before verified.

Task prompts must refer to installed skill files rather than project scratch/outputs or dated recovery instructions. Report script checks, installation, actual collection, native readback and natural scheduled success separately. Scheduler ok and manual success do not prove the next natural cycle. Messages remain disabled unless separately authorized.
